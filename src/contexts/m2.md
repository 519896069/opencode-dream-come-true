# M2: 任务拆分

**需要用户确认：** ✓

**产物：** tasks.md

## 执行流程

1. **调用代码规范 skill**
   ````
   skill(name: "standards")
   ````

2. **读取设计文档**
   - 读取 design.md
   - 读取 api.json

3. **识别交叉定义**
   - 分析 dto、entity、model 等交叉定义
   - 为交叉定义生成前置任务（P0 优先级）

4. **拆分任务**
   - 每个接口/组件/函数拆为一个 Task
   - 分析依赖关系
   - 确定执行顺序

5. **生成 tasks.md**
   - 依赖关系图
   - 执行顺序
   - 上线标准
   - 每个任务的详细信息：
     - 工作目录
     - 任务依赖
     - 工作内容
     - 详细逻辑设计
     - 边界情况处理
     - 函数链路图
     - 测试用例
     - 风险评估
     - 审查要点
     - 验收标准

6. **验证产物**
   - 调用 dct_validate 验证 tasks.md

7. **用户确认**
   - 询问用户是否通过
   - 如果不通过，根据反馈修改产物

8. **更新看板状态**
    - 修改 kanban.md，将 M2 标记为已完成
    - 将编码任务添加到看板
