# 阶段一：需求澄清

## 阶段产物

| 产物 | 说明 |
|------|------|
| `prd/{YYYY-MM-DD-<英文简述>}/requirement.md` | 功能概述 + 功能范围 + 外部依赖 |
| `prd/{YYYY-MM-DD-<英文简述>}/fields.md` | 字段定义 |
| `prd/{YYYY-MM-DD-<英文简述>}/checkpoint.md` | 验收条件 checklist |
| `prd/{YYYY-MM-DD-<英文简述>}/boundary.md` | 业务流程 + 权限 + 数据量级 + 边界条件 + 非功能需求 |

---

## 产物规范

### 1. `prd/{YYYY-MM-DD-<英文简述>}/requirement.md`

```markdown
# 需求文档: {需求标题}

## 1. 功能概述

{一段话精确描述这个需求要做什么}

## 2. 功能范围

### 包含
- 功能点1
- 功能点2

### 不包含
- 明确不做的事情1
- 明确不做的事情2

## 3. 外部依赖

### 已有模块依赖
| 模块 | 依赖内容 | 接口 |
|------|------|------|
| 用户体系 | 复用登录态、用户 ID | GetCurrentUser |

### 外部系统依赖
| 系统 | 依赖内容 | 接口 |
|------|------|------|
| OSS | 文件上传 | PutObject |

### 第三方库依赖
| 库 | 用途 |
|------|------|
```

### 2. `prd/{YYYY-MM-DD-<英文简述>}/fields.md`

```markdown
# 字段定义

## 实体: {实体名}

| 字段名 | 类型 | 长度 | 必填 | 默认值 | 说明 | 校验规则 |
|--------|------|------|:--:|------|------|------|
| id | bigint | - | 是 | 自增 | 主键 | - |
| name | string | 50 | 是 | - | 名称 | 1-50 字符，非空 |
| status | int | - | 是 | 1 | 状态 | 枚举：1=启用 2=禁用 |
| created_at | datetime | - | 是 | now | 创建时间 | - |

## 实体: {实体名2}
...
```

### 3. `prd/{YYYY-MM-DD-<英文简述>}/checkpoint.md`

```markdown
# 验收条件

## 正常流程
- [ ] 验收点1：{可测试的具体行为描述}
- [ ] 验收点2

## 异常流程
- [ ] 验收点：字段为空时提示必填
- [ ] 验收点：数据不存在返回 404

## 边界条件
- [ ] 验收点：超长输入时的处理
- [ ] 验收点：并发操作时的处理
```

### 4. `prd/{YYYY-MM-DD-<英文简述>}/boundary.md`

```markdown
# 边界条件与约束

## 1. 业务流程

{状态流转文字描述，或关键操作步骤}

## 2. 权限定义

| 角色 | 可执行操作 | 数据范围 |
|------|------|------|
| 管理员 | 增删改查 | 全部数据 |
| 普通用户 | 查 | 仅自己的数据 |

## 3. 数据量级

| 维度 | 预估 |
|------|------|
| 数据总量 | 万级 |
| 单页数量 | 20 条 |
| 是否需要分页 | 是 |
| 是否需要导出 | 否 |
| 是否需要批量操作 | 否 |

## 4. 边界条件

| 场景 | 预期行为 |
|------|------|
| 字段为空 | 提示必填 |
| 数据不存在 | 返回 404 |
| 并发操作 | 乐观锁，提示"数据已被修改" |
| 超长输入 | 按长度限制截断并提示 |

## 5. 非功能需求

| 维度 | 要求 |
|------|------|
| 响应时间 | 列表查询 < 200ms |
| 安全 | 需登录校验 |
| 日志 | 关键操作记录操作日志 |
```

---

## 质量标准

- 功能范围包含和不包含都明确列出
- 所有字段有类型、长度、必填标记、校验规则
- 验收条件可测试、可验证，区分正常/异常/边界三类
- 权限定义覆盖所有操作角色，含数据范围
- 边界条件覆盖空状态、错误状态、极端值、并发
- 外部依赖列出接口或字段级依赖，不写模糊的模块名
