# 阶段二：设计分析报告

## 产物说明

| 产物 | 说明 |
|------|------|
| `prd/{YYYY-MM-DD-<英文简述>}/design-analysis.md` | 设计分析报告（含设计决策点） |

## 格式要求

设计分析报告是 design.md 的数据来源，包含所有技术分析和设计决策点。后续生成 design.md、api.json、test-case.md 时直接读取此报告，防止分析上下文丢失。

## 质量标准

- 所有数据库变更结论必须有 vs 真实表的对比依据
- 所有"可复用"结论必须标注文件路径和行号
- 每一节都有可勾选的确认清单
- 设计决策点必须包含：选项 A/B、说明、优缺点
- 决策结果记录必须包含：选择、决策时间、备注
- 后续生成 design.md、api.json、test-case.md 时直接读取此报告
